# 「2026 주간시사 9월 3주」 레퍼런스 분석

분석 대상: `2026주간시사 9월3주_표지포함.pdf` (24쪽, A4 세로 595×842pt).

## 공통 페이지 규칙

- 본문은 약 20mm 좌우, 25mm 상단, 22mm 하단의 읽기 영역을 사용한다.
- 본문 1~19쪽은 좌측 `김윤환입시연구소 시사 읽기자료집`, 우측 `www.pogara.com`, 바로 아래의 얇은 회색 선을 반복한다.
- 하단은 얇은 검정 선, 좌측 파란 URL, 우측 숫자 쪽수이다. 문서 안쪽 페이지 번호는 표지 이후 1부터 시작한다.
- 본문은 검정/짙은 회색 산세리프 한글, 약 9pt, 15pt 안팎 줄간격의 양쪽 정렬이다. 문단 사이는 약 7pt다.
- 이미지는 본문 폭 또는 우측 약 1/3 폭으로 배치된다. 캡션은 6~7pt로 이미지 바로 아래에 둔다.

## 표지와 첫 페이지

- 표지는 밝은 중간 회색 배경, 좌상단 브랜드/연도, 중앙의 `시사 읽기자료집`과 `세상의 많은 이야기들`, 하단 우측 KAIROS ACADEMY로 구성된다.
- 선형 원·막대·별 모티프가 여백을 채우는 기하 그래픽 역할을 한다.
- 첫 본문 페이지에는 `김윤환CLASS`, `시사 읽기자료집`, 주차/날짜 범위, 상단 이미지와 구분선이 배치된다.

## 섹션과 기사 규칙

- 섹션은 `주간시사 N | 주제`가 들어간 회색 바(약 8mm 높이)로 시작하며, 흰색 굵은 10pt 글자를 쓴다. 위 7mm·아래 5mm 여백이 있다.
- 기사는 13pt 굵은 제목(18pt 줄간격), 8pt 안팎의 `언론사 | 기자 | 날짜` 메타데이터, 기사 본문 순서다. 원본 URL은 재현 엔진에서 메타데이터 다음 줄에 보존한다.
- 기사 흐름은 다음 기사 제목이 이어지는 연속 조판이며, 이미지는 원본 비율을 유지하고 본문을 가리지 않는다.
- 마지막 21~23쪽은 메모 연습란, 24쪽은 브랜드 클로징 페이지다. 현재 엔진의 기본 렌더링 범위는 표지와 기사 본문이며, 메모/클로징은 향후 템플릿 확장 포인트다.

모든 재현 가능 수치는 `templates/weekly_current_affairs.json`에 코드와 분리해 저장했다.
